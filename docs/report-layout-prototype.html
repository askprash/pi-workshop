🚧 Before you proceed

The single blocking concern

The missing-model error path emits a raw internal exception instead of a user-facing message with the fix command. Any first user without a pre-configured model will bounce here before the extension does anything useful.

Decisions you need to make

  • Rewrite the missing-model error to include the exact pi --list-models + config snippet needed to fix it.
  • Add an integration test: "run without strongModel configured, assert error message contains the fix command."
  • Add a policy clarification: "artifact-contained means files written by the tool; the subprocess itself is an unsandboxed local shell."

Prior art & related work

Similar projects the panel found while researching this idea.

LangGraph Multi-Agent Supervisor

LangChain's supervisor pattern runs N specialist agents and routes between them based on task type. The privilege boundary is handled by giving each agent a fixed tool subset at instantiation, not at call time — similar to the expert-tool scoping decision here.

AutoGen Agent Sandbox

Microsoft's AutoGen v0.4 introduced a Docker-based code execution sandbox with explicit "allowed" vs "disallowed" tool registries per agent. The "artifact-contained, not sandboxed" framing here contrasts directly with AutoGen's stronger isolation — and the tradeoff is the same: sandboxing adds latency and setup cost.
